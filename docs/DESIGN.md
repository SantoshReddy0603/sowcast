# Design

Sowcast uses a field-notebook layout for one task at a time: choose a plot, then read the dated plan. The current interface contains Plot, Plan, Ask and Reliability. Reliability uses a single directly labelled bar chart and a temperature-error table, with explicit sample counts, grid differences and unavailable probabilities.

The paper background is #f5f2e9, ink #232c25, muted text #5e655b, clay accent #91462f and a restrained neutral green for rainfall. Headings use Newsreader, controls IBM Plex Sans, with Noto Sans and Devanagari/Kannada/Telugu/Tamil fallbacks. Google Fonts supplies the requested families; local serif/sans fallbacks remain when fonts cannot load. The interface is English in this delivery. It does not claim translated advice.

Spacing uses a four-pixel base with additional ten-pixel gaps and padding. Desktop uses a 4fr/7fr plot split and a gap; mobile stacks the introduction and form into one column. Type scales from 16px body to fluid editorial headings. Inputs and primary controls are at least 44px high. The clay is reserved for selection, evidence links and the main action. There are no gradients, glass surfaces, decorative imagery, repeated metric cards or hero promotion.

Plot supports live search, a real OpenStreetMap tile layer, click selection, keyboard map panning plus a Pin map centre button, and typed coordinate fallback. The map starts at a broad India viewport but has no selected plot, crop or district. Sowing status distinguishes unsown from growing; growing requires a supplied sowing date. A coordinate lookup uses simplified 2021 district boundaries to suggest the district. The user can correct the selection; near-boundary and unsupported locations remain explicit. Reference FAO estimates are opt-in.

Plan makes the dated tasks the main content. Each task has its own date, reason and expandable input/citation evidence. A slim heat/water/flood strip reports an actual assessment or says not assessed; discharge alone never becomes a flood-risk level. Weather and dated tasks show source/fetch times. Optional soil and retrospective NASA evidence can be requested separately; their absence never replaces field measurements or blocks the plan.

The weather chart is a hand-built SVG with d3-scale/d3-shape: a temperature band and rainfall bars, both directly labelled, using UTC dates. It has an accessible description and the exact daily values remain in the task disclosures. Missing temperature values leave paths undefined; missing calendar dates split the band and retain real temporal spacing. Mobile contains horizontal chart scrolling rather than shrinking labels or overflowing the page. An optional ERA5 1991–2020 calendar-day comparison adds historical lines, a legend and an exact-value table. These gridded averages are not station normals; coverage counts and missing/stale/error states remain visible.

Loading shapes follow the plan's title, risk strip and rows. Search and plan failures have readable messages and retry paths. Empty search, missing fields, absent stage rules, source outages and stale forecasts have explicit wording. A new request clears old results, and cancellation prevents older responses from replacing the current plot. Native details/summary controls preserve keyboard disclosure behavior. Form controls have labels, a skip link precedes navigation, focus is visible, and screen changes send focus to the view boundary. prefers-reduced-motion disables animation; prefers-color-scheme supplies dark tokens. The UI uses a single inline line-drawn plant mark; no icon dependency is installed.

Primary text/accent/background token pairs were checked numerically, and real browser checks exercised mobile width and keyboard order. This is not a full WCAG conformance audit. Map tiles, remote font availability and upstream coverage depend on external services. SoilGrids uncertainty and NASA latency are recorded in DATA_SOURCES.md.

Reliability labels every score group GFS model and exposes both rain definitions through a labelled selector. It shows paired counts beside ERA5 rain shares, majority baselines and approximate intervals. The page explains UTC days as 05:30-to-05:30 IST and makes no claim that one lead is better. Intervals assume independent days; temporal correlation is an explicit limit.

Real local-container captures exist at images/plan.png and images/reliability.png. Desktop and 390px browser checks exercised chart containment, keyboard access, source failure and missing/stale states. These checks do not establish complete accessibility conformance or mobile speech behavior.

Returning to Plan from another view requests a new plan. The old plan is cleared while loading and remains absent if refresh fails. Source-cache timestamps and stale flags retain their original evidence age.
