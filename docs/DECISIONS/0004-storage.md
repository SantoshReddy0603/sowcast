# Storage and migrations

SQLAlchemy models and explicit Alembic revisions support SQLite/aiosqlite locally and PostgreSQL/asyncpg for hosted deployment. Initial migration adopts existing local tables without deleting rows. PostgreSQL transaction locks preserve lease ownership and bounded retention. Hosted records are kept outside the API filesystem, which free hosts may erase. DATABASE_URL selects the runtime storage connection; an earlier provider comparison does not establish the deployed database vendor. Local development uses SQLite, while production mode requires PostgreSQL with explicit TLS.
