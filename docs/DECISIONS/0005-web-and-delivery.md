# Web and delivery

Strict TypeScript, React, Vite and plain CSS keep the four views small without a component framework. SVG charts use D3 scales/shapes and explicit missing-data gaps. Only two charts exist. Docker images pin immutable base digests and use non-root runtime users. Render hosts both the web at https://sowcast-web.onrender.com and API at https://sowcast-api-820y.onrender.com. The web uses an explicit public API origin; API storage comes from DATABASE_URL and /health is the process check. Continuous database health polling is avoided so an idle database can scale down. Configuration files alone do not change the running services; Vercel configuration remains in the repository but is not the current web host.
